# MyCar versions

Current version is defined only in version.js. The footer and Settings read it.

Starting release: v1.0. Increment the minor number for each subsequent user-approved published update: v1.1, v1.2, etc. Multiple commits belonging to one update share a version. Move to v2.0 only for a major update agreed with the user.

For each release, update version.js and the version query strings for version.js, app.js and style.css in index.html together. Do not reset or derive versions from deployment retries or individual commits.
