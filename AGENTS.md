# MyCar

## REPOSITORY HYGIENE – MANDATORY

La fiecare implementare, modificare, actualizare sau publicare:

1. Verifică dacă modificările introduse fac inutile fișiere existente.
2. Elimină fișierele înlocuite sau abandonate numai după confirmarea că nu mai sunt utilizate.
3. Nu păstra copii ale versiunilor anterioare în structura activă a repository-ului. Utilizează istoricul Git pentru recuperarea acestora.
4. Nu încărca fișiere temporare, mockup-uri, backup-uri locale sau resurse de testare care nu sunt necesare proiectului.
5. Reutilizează fișierele existente atunci când este posibil.
6. Verifică și actualizează referințele din manifest, service worker și cache atunci când sunt modificate resursele aplicației.
7. Nu elimina fișiere cu dependențe neconfirmate.
8. Include verificarea resurselor neutilizate în checklist-ul obligatoriu înainte de publicare.
9. Limitează verificarea la fișierele afectate de actualizarea curentă. Efectuează audituri complete numai când sunt necesare sau solicitate explicit.
10. Păstrează istoricul Git și posibilitatea de rollback.

Această regulă trebuie respectată la toate intervențiile viitoare asupra MyCar.
